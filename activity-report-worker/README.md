# 활동 보고서 일꾼

문화 프로그램이 끝나면 **참가자 명단**과 **진행 메모**를 폴더에 넣고 "활동 보고서 써 줘"라고 말하세요.
참석 인원과 진행 내용이 담긴 **활동 보고서 초안**이 나옵니다.

지역에서 문화 프로그램을 여는 담당자 누구나 받아 쓸 수 있게 만들었습니다.

> 이 저장소의 명단과 메모는 모두 **가짜 자료**입니다. 실제 인물과 관계없습니다.

---

## 무엇이 들어 있나요

| 파일 | 하는 일 |
|---|---|
| `SKILL.md` | AI에게 주는 일의 설명서(스킬 파일) |
| `예제/참가자명단.csv` | 가짜 참가자 10명 명단 |
| `예제/진행메모.txt` | 가짜 프로그램 「가을 문화 나들이」 진행 메모 |
| `결과/활동보고서_가을 문화 나들이.md` | 예제 자료로 돌려 본 결과 |

## 쓰는 방법

1. 이 저장소에서 **Code → Download ZIP**을 눌러 내려받고 압축을 풉니다.
2. 풀어 놓은 폴더 안에 내 프로그램의 **명단**과 **메모**를 넣습니다. (모양은 아래 참고)
3. Claude에게 이 폴더를 열어 주고 이렇게 말합니다.
   > SKILL.md 대로 활동 보고서 써 줘.
4. `결과` 폴더에 보고서 초안이 생깁니다. **인원과 날짜는 꼭 직접 확인**하세요.

> Claude 앱에서 스킬로 등록해 두고 쓰셔도 됩니다. `SKILL.md`만 있으면 됩니다.

## 명단은 이렇게 만드세요

엑셀이나 CSV로, 첫 줄에 칸 이름을 둡니다. **이름**과 **참석 여부**는 꼭 있어야 합니다.

| 번호 | 이름 | 연령대 | 참석 여부 | 메모 |
|---|---|---|---|---|
| 1 | 홍길동 | 60대 | 참석 | |
| 2 | 김철수 | 40대 | 불참 | 사전 취소 |

- 참석 여부는 `참석` / `불참` 둘 중 하나로 씁니다.
- 연령대와 메모는 없어도 됩니다.

## 메모는 이렇게 쓰세요

첫 줄에 **프로그램 이름 / 날짜 / 장소**, 그 아래에 한 줄씩 적습니다.

```
프로그램: 가을 문화 나들이 / 2026-11-14(토) 10:00~15:00 / 장소: ○○시 역사문화공원
- 10:00 모임, 둘레길 걷기
- 11:30 공예 체험
- 다음 달 겨울 공예 교실 요청 있음
```

## 보고서에 들어가는 것

프로그램 · 날짜 · 장소 · 참석 인원(참석률) · 진행 내용 · 참가자 반응 · 운영하며 알게 된 점 · 다음 계획

칸을 빼거나 더하고 싶으면 `SKILL.md`의 「보고서 모양」을 고치면 됩니다.

## 꼭 지켜 주세요

- **진짜 명단은 깃허브에 올리지 마세요.** 깃허브는 누구나 볼 수 있습니다. 내 자료는 내 컴퓨터 폴더에만 둡니다.
- 보고서에는 참가자 이름이 들어가지 않게 만들었습니다. 그래도 내보내기 전에 한 번 더 확인하세요.
