# 활동 보고서 일꾼

참가자 명단과 진행 메모를 읽고, 같은 모양의 활동 보고서 초안을 만든다.

## 받는 것
- **참가자 명단** (CSV 또는 엑셀): `이름`, `참석 여부` 칸이 꼭 있어야 한다. `연령대`, `메모` 칸은 있으면 쓴다.
- **진행 메모** (텍스트): 첫 줄에 프로그램 이름 · 날짜 · 장소, 그 아래 한 줄씩 진행 내용.

## 순서
1. 명단과 메모 파일을 찾는다. 둘 중 하나가 없으면 무엇이 빠졌는지 말하고 멈춘다.
2. 명단에서 세기: 신청 인원, 참석 인원, 불참 인원, 참석률(참석 ÷ 신청). 연령대 칸이 있으면 연령대별 참석 인원도 센다.
3. 메모에서 뽑기: 프로그램 이름, 날짜, 장소, 진행 내용, 참가자 의견, 다음 계획.
4. 아래 모양으로 `결과/활동보고서_(프로그램 이름).md` 파일을 만든다.
5. 다 만들면 숫자(인원, 날짜)를 사람이 직접 확인해 달라고 말한다.

## 보고서 모양
```
# 활동 보고서 — (프로그램 이름)

| 항목 | 내용 |
|---|---|
| 프로그램 | |
| 날짜 · 시간 | |
| 장소 | |
| 참석 인원 | 참석 ○명 / 신청 ○명 (참석률 ○%) |

## 1. 진행 내용
(시간 순서로 3~5줄)

## 2. 참가자 반응
(메모에 적힌 의견만. 없으면 "메모에 없음")

## 3. 운영하며 알게 된 점
(안전, 이동, 준비물 등 다음에 챙길 것)

## 4. 다음 계획
(메모에 적힌 요청·계획. 정해지지 않은 것은 "미정"이라고 쓴다)
```

## 지킬 것
- 보고서에 **참가자 이름을 쓰지 않는다.** 숫자와 연령대로만 쓴다. (예: "70대 참가자 1명")
- 명단의 메모 칸에 있는 건강·사정 내용은 보고서에 옮기지 않는다. 운영에 필요한 것만 "이동 지원 필요 1명"처럼 이름 없이 쓴다.
- 메모에 없는 내용은 지어내지 않는다.
- 숫자가 맞지 않으면(예: 메모의 인원과 명단이 다름) 보고서 끝에 "확인 필요"로 적는다.
